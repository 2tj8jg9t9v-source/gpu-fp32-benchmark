# GPU FP32 Benchmark

Браузерный тест вычислительной производительности FP32 для телефона и компьютера. Страница не требует сборки, установки приложений или сторонних библиотек; вычисления выполняются на GPU через WebGPU.

## Запуск

Откройте `index.html` в браузере с поддержкой WebGPU по HTTPS или на `localhost`. Для телефона используйте актуальные версии Chrome на Android или Safari на iPhone. Доступность WebGPU зависит от модели устройства, версии ОС и браузера.

Нажмите **«Запустить тест»** и выберите короткий тест на 5 секунд или подробный на 15 секунд. Скорость выводится в TFLOP/s (FP32). Измерение включает время выполнения и отправки вычислений в браузере; сравнивайте результаты при одинаковых условиях.

После теста можно поделиться результатом и ссылкой на страницу встроенными средствами телефона.

## Публикация

Чтобы включить публичную страницу, откройте **Settings → Pages** репозитория и выберите **GitHub Actions** как источник. Затем запустите workflow **Deploy static site to GitHub Pages**. Сайт будет доступен по адресу `https://2tj8jg9t9v-source.github.io/gpu-fp32-benchmark/`; последующие push в `main` будут публиковаться автоматически.
